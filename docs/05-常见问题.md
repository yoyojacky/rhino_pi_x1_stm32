# 05 - 常见问题排查

## 一、烧录类问题

### 1. `Found 0 stlink programmers` / `Couldn't open ST-Link`

系统根本没看到 ST-Link：

```bash
lsusb | grep -i 0483
```

- 没有输出 → USB 层面就没识别：换 USB 线（**很多线是充电线，没有数据线！**）、
  换 USB 口、检查 ST-Link 是否插紧。
- 有输出但 st-flash 连不上 → 多半是**权限问题**，见下一条。

### 2. 权限问题（Permission denied / libusb_open failed）

Linux 默认普通用户不能访问 USB 设备。两种解法：

**方法一（临时验证）**：加 sudo 跑一次

```bash
sudo st-info --probe
```

能通就确认是权限问题。

**方法二（一劳永逸）**：安装 udev 规则，让普通用户也能访问 ST-Link。
stlink-tools 的 apt 包通常已自带规则文件，检查：

```bash
ls /lib/udev/rules.d/ | grep -i stlink
```

有的话执行：

```bash
sudo udevadm control --reload-rules
sudo udevadm trigger
```

然后**拔掉 ST-Link 重新插上**，再试 `st-info --probe`（不加 sudo）。

没有规则文件的话手动建一个：

```bash
echo 'SUBSYSTEM=="usb", ATTR{idVendor}=="0483", ATTR{idProduct}=="3748", MODE="0666"' \
  | sudo tee /etc/udev/rules.d/49-stlinkv2.rules
sudo udevadm control --reload-rules
# 重新拔插 ST-Link
```

### 3. `chipid: 0x0000` 或识别不到芯片（但 ST-Link 本身正常）

ST-Link 是好的，但它和 STM32 之间的 SWD 通信失败：

- **SWDIO / SWCLK 接反了** → 对调这两根线（最常见）
- STM32 板没供电 → 检查 3.3V 和 GND，板子电源灯亮不亮
- 杜邦线接触不良/太长 → 换线，缩短到 15cm 内
- 板子上的 BOOT0 跳帽被拨到了 1 → 拨回 0（正常应从 Flash 启动）

### 4. 提示读保护（Read Protection / RDP）

芯片被开了读保护（比如之前烧过带保护的程序）。解除（会**清空整个芯片**）：

```bash
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg \
    -c "init" -c "stm32f1x unlock 0" -c "reset halt" -c "exit"
```

然后再正常 `make flash`。

### 5. 烧录到一半断掉 / 校验失败

- 供电不稳：确认 ST-Link 的 3.3V 能带动板子，或改用板子 USB 供电、
  ST-Link 只接 SWDIO/SWCLK/GND 三根线（**此时千万不要把两个 3.3V 并在一起**）
- 线太长/干扰大：换短且质量好的杜邦线

## 二、电机类问题

### 1. 驱动板 4 个 LED 轮流闪，但电机不转

信号链路正常，问题在功率侧：

- 驱动板 `+` 没接 5V，或接到了 3.3V（电压不够，力矩不足）
- 驱动板与 STM32 **没有共地**（`-` 必须和 STM32 的 GND 连一起）
- 电机插头没插紧
- 电机轴上负载太重，空载试试

### 2. 电机抖动、嗡嗡响、原地乱晃不走

典型的**失步**或**相序错误**：

- `STEP_DELAY_MS` 太小 → 改大（比如 4~5）再试
- IN1~IN4 顺序接错 → 严格按 PA1→IN1、PA2→IN2、PA3→IN3、PA4→IN4，
  中间任意两根对调都会导致乱序
- 供电不足：ST-Link 的 5V 引脚电流能力有限，如果电机带负载，
  建议驱动板用独立 5V 电源（仍然要共地！）

### 3. 电机只朝一个方向转，反转时不走

- 检查代码里 `dir` 参数是否被改动
- 大概率还是相序或供电问题，按上一条排查

### 4. 电机转动时 STM32 重启/掉线

电机是感性负载，启停瞬间电流冲击大，把供电拉垮了：

- 驱动板改用独立 5V 供电
- 或在驱动板电源端并一个 100µF~470µF 电解电容

## 三、编译类问题

### 1. `make: arm-none-eabi-gcc: Command not found`

工具链没装：

```bash
sudo apt install gcc-arm-none-eabi binutils-arm-none-eabi
```

### 2. 链接报错 `cannot find -lc` / specs 相关错误

缺 newlib 规范文件，安装完整包：

```bash
sudo apt install libnewlib-arm-none-eabi
```

### 3. 编译警告 `warning: ...`

`-Wall` 打开的警告尽量都改掉；不理解就按警告提示的行号去看代码。

## 四、查资料的正确姿势

入门阶段最重要的两份官方文档（搜索引擎直接搜编号即可）：

| 文档 | 内容 |
|---|---|
| **RM0008** | STM32F103 参考手册：所有寄存器的每一位是什么意思 |
| **STM32F103x8/B 数据手册 (Datasheet)** | 引脚定义、电气参数（哪个引脚能干什么、耐不耐 5V） |

遇到"这个寄存器为什么这样写"的问题，答案一定在 RM0008 里。
